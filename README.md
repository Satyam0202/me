# Satyam Kumar — Portfolio

A dark/light-mode developer portfolio built with plain HTML, CSS and JavaScript (no build step required).

## Files
- `index.html` — page structure, content, and SEO/structured data
- `style.css` — design tokens, layout, dark/light theme, animations
- `script.js` — theme toggle, typing effect, mobile nav, scroll reveals
- `assets/` — put your photo, resume PDF, and social-preview image here

## Before you publish — replace these placeholders

1. **Resume** — add your file at `assets/Satyam_Kumar_Resume.pdf` (linked from the hero and the Resume section).
2. **Contact links** — in `index.html`, swap:
   - `satyam.kumar@example.com` → your real email
   - `https://linkedin.com/in/your-linkedin` → your LinkedIn URL
   - `https://github.com/your-github` → your GitHub URL
   (also update the two matching URLs inside the `<script type="application/ld+json">` block)
3. **Canonical/OG URL** — replace `https://satyamkumar.dev/` with your live domain in the `<meta>` tags and JSON-LD, once you have one.
4. **Project links** — each project card's "Live demo" / "Source code" buttons currently point to `#`; point them at your deployed apps and repos.
5. **Project copy** — `AutoForm AI`'s description reflects the real build (Electron + React + TypeScript + Vite + Playwright, local-profile form automation). `StreamVerse` and `AI City Companion` currently have reasonable placeholder descriptions and tech stacks — edit them to match your actual implementations.
6. **Avatar** — the circular hero avatar currently shows initials "SK". To use a real photo, replace the `.avatar-circle` `<span>SK</span>` in `index.html` with an `<img>` tag pointing at a photo in `assets/`.
7. **Social preview image** — add `assets/og-cover.png` (1200×630px) for link previews, or remove the `og:image` / `twitter:image` tags.
